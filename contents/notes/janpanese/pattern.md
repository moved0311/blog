| 我有           |                            | 車を 持っています                                                          |

| 請不要做         | ない形 でください                  | 写真を 撮らないで ください 請不要拍照 [[grammar#Lesson 17\|Lesson 17]]              |

| 請做某事         | て形 ください                    | ここに書いてください 請寫在這裡<br/>少し待ってください請稍等片刻                                |
| 請不要做某事       | ないでください                    | 辛くしないでください 請不要做辣的                                                  |
| 可以...嗎？      | て形 + もいいですか                |                                                                    |
| 想做某事(動作)     | ~~ます~~ + たいです              | 寿司を食べたいです [[grammar#Lesson 13\|Lesson 13]]                         |
| 去做           | ~~ます~~ + に行きます             | 私は フランスへ 料理を 習いに 行きます<br/>[[grammar#Lesson 13\|Lesson 13]]         |
| 要不要(為你)做     | ~~ます~~ + ましょうか             | 荷物を 持ちましょうか 要不要幫你拿行李 ? <br /> [[grammar#Lesson 14\|Lesson 14]]     |
| 可以 / 許可表現    | て形もいいです                    | 写真を 撮っても いいですか?<br/>飲み物を飲んでもいいです 可以喝東西                             |
| 禁止/不可以       | て形 はいけません                  | お酒を 飲んでは いけません 不能喝酒                                                |
| 動作順序         | て形、て形、～ます                  | 朝 ジョギングを して シャワーを 浴びて 会社へ 行きます 早上慢跑、洗澡然後去公司                        |
| 做~之後         | て形から                       | コンサートが 終わってから、レストランで 食事しました 音樂會結束後，在餐廳用餐                           |
| 既A又B         | Aて形、B                      | この部屋は 広くて、明るいです <br/>這個房間又寬敞又明亮                                    |
| 不做不行/一定要做    | ~~ない~~形なければなりません           | パスポートを 見せな ければ なりません 你必須出示護照                                       |
| 沒必要做         | ~~ない~~形なくても いいです           | 日曜日は 早く 起きなくても いいです 星期日不必早起                                        |
| 會做           | 辭書形ことが できます                | ラーさんは字を読むことが できます 米勒先生會讀漢字                                         |
| 做A之前做B       | A辭書形まえに、B                  | 寝るまえに 日記を 書きます 睡覺前寫日記                                              |
| 有做過          | た形ことが あります                 | 相撲を 見たことが あります 我看過相撲 [[grammar#Lesson 19\|Lesson 19]]              |
| 做A做B (動作列舉)  | た形り、た形りします                 | 休みの日は テニスをしたり、散歩に行ったりします                                           |
| 猜想 / 覺得 / 認為 | 普通形と思います<br>な形容詞/名詞＋だ      | わたしは あした 雨が 降ると 思います <br>我猜想明天會下雨 [[grammar#Lesson 21\|Lesson 21]] |
| ~吧？/ ~對不對    | 普通形でしょう？ <br>(な形容詞/名詞不用加だ) | 疲れた でしょう？ 累了吧?<br>確認：昨日地震がおったでしょう？<br>要求同意：この店のラーメン、美味しいでしょう？      |
