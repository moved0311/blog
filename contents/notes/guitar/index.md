相鄰格子差半音
- 半音(H, Half Step)1格
- 全音(W, Whole Step) 2格

$$
\mathrm{C}
\;\xrightarrow{\text{全音}}\;
\mathrm{D}
\;\xrightarrow{\text{全音}}\;
\mathrm{E}
\;\xrightarrow{\text{半音}}\;
\mathrm{F}
\;\xrightarrow{\text{全音}}\;
\mathrm{G}
\;\xrightarrow{\text{全音}}\;
\mathrm{A}
\;\xrightarrow{\text{全音}}\;
\mathrm{B}
\;\xrightarrow{\text{半音}}\;
\mathrm{C}
$$

音階: 
每條弦差4度音 (完全四度=5個半音)
但是第三弦到第二弦 G -> B (大三度, 四個半音) 
- 跨 G → B 弦時，要補一格，因為少半音

為什麼要有一條弦不一樣 ?
- 全部都是完全四度，那很多和弦會變得非常難按

八度音(Octave): 同一個音名高八度的音。差12個半音

## CAGED SYSTEM

找不同位置的C, F, G 和弦位置

1. 用同一種指形(C, A, G, D)分別彈 C -> F -> G -> F
	- 會依照CAGED的順序輪流: C -> A指形的C -> G指形的C -> D指形的C -> C指形的C
2. 在同一個把位按出C -> F -> G -> F
