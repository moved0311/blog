- 半音(H, Half Step)1格
- 全音(W, Whole Step) 2格

$$
\mathrm{C}
\;\xrightarrow{\text{全音}}\;
\mathrm{D}
\;\xrightarrow{\text{全音}}\;
\mathrm{E}
\;\xrightarrow{\text{半音}}\;
\mathrm{F}

\mathrm{G}

\mathrm{A}

\mathrm{B}

$$

## C大調

第一個音從C開始依照全全半全全全半的順序填

| 1   |     | 2   |     | 3   | 4   |     | 5   |     | 6   |     | 7   |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| C   |     | D   |     | E   | F   |     | G   |     | A   |     | B   |

大三和弦 1-3(大三度)-5(完全五度)的規則組成的和弦

- 1: Root
- 3: 和Root是大三度(差4個半音)關係
- 5: 和3是小三度(差三個半音)關係

| 和弦 | 組成音 | 級數 |
| ---- | ------ | ---- |
| C    | 135    | i    |
| Dm   | 246    | ii   |
| Em   | 357    | iii  |
| F    | 461    | iv   |
| G    | 572    | v    |
| Am   | 613    | vi   |
| Bdim | 724    | vii  |

大調音階規則: 2,3,6會是minor(小和弦), 7是diminished(減和弦)

## 高把位音階
