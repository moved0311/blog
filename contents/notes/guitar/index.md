## C大調
第一個音從C開始依照全全半全全全半的順序填

| 1   |     | 2   |     | 3   | 4   |     | 5   |     | 6   |     | 7   |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| C   |     | D   |     | E   | F   |     | G   |     | A   |     | B   |

大三和弦 1-3(大三度)-5(小三度)的規則組成的和弦
- 1: Root
- 3: 和Root是大三度(差4個半音)關係
- 5: 和3是小三度(差三個半音)關係

| 和弦   | 組成音 | 級數  |
| ---- | --- | --- |
| C    | 135 | i   |
| Dm   | 246 | ii  |
| Em   | 357 | iii |
| F    | 461 | iv  |
| G    | 572 | v   |
| Am   | 613 | vi  |
| Bdim | 724 | vii |

大調音階規則: 2,3,6會是minor(小和弦), 7是diminished(減和弦)

## CAGED SYSTEM
****
找不同位置的C, F, G 和弦位置

1. 用同一種指形(C, A, G, D)分別彈 C -> F -> G -> F
	- 會依照CAGED的順序輪流: C -> A指形的C -> G指形的C -> D指形的C -> C指形的C
2. 在同一個把位按出C -> F -> G -> F
